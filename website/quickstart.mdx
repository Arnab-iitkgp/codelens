title: Quick Start

CodeLens is designed to be self-hosted. The pipeline relies heavily on Next.js background jobs (via Inngest) and a vector database (Pinecone) to store your AST graphs.

## Prerequisites

Before you start, ensure you have the following installed:
- [Node.js](https://nodejs.org/en/) (v18+) or [Bun](https://bun.sh/)
- A [Pinecone](https://pinecone.io/) account (the free tier is plenty)
- A PostgreSQL database (we recommend [Neon](https://neon.tech/))

## 1. Clone the Repository

```bash
git clone https://github.com/Arnab-iitkgp/codelens.git
cd codelens
bun install
```

## 2. Environment Variables

Create a `.env` file in the root of the project. You can copy `.env.example` if it exists.

```ini .env
# Database & Auth
DATABASE_URL="postgresql://user:password@host:port/dbname"
BETTER_AUTH_SECRET="your-super-secret-auth-key"
BETTER_AUTH_URL="http://localhost:3000"

# GitHub App Credentials
GITHUB_CLIENT_ID="your_github_client_id"
GITHUB_CLIENT_SECRET="your_github_client_secret"
NEXT_PUBLIC_APP_BASE_URL="http://localhost:3000" # Or your ngrok URL for webhooks

# Vector DB
PINECONE_DB_API_KEY="your-pinecone-key"
PINECONE_INDEX_NAME="codelens-vector-embedding-v3"

# AI Provider Setup (Example: Groq)
AI_PROVIDER="groq"
AI_MODEL_ID="openai/gpt-oss-120b"
GROQ_API_KEY="gsk_your_key_here"

# Background Jobs
INNGEST_EVENT_KEY="local"
INNGEST_DEV=1
```

<Note>
If you are running the Inngest dev server locally, it is critical that `INNGEST_DEV=1` is set in your `.env` so Next.js doesn't block the sync requests.
</Note>

## 3. Database Migration

Run the Prisma migrations to set up your PostgreSQL schema:

```bash
bunx prisma migrate dev
```

## 4. Boot the Engines

You need to run two servers side-by-side: the Next.js app, and the Inngest background job executor.

Open your **first terminal** and start Next.js:
```bash
bun run dev
```

Open a **second terminal** and start Inngest:
```bash
bunx inngest-cli@latest dev
```

Your CodeLens dashboard is now live at `http://localhost:3000`! You can log in via GitHub OAuth, connect a repository, and let the AST indexer run in the background.
