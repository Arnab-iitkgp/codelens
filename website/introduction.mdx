CodeLens is an open-source, self-hostable AI code review engine for GitHub Pull Requests. 

While most AI coding tools act as simple wrappers around an LLM chat interface, CodeLens is designed around a core thesis: **the pipeline carries the load, not the model.**

By forcing the Large Language Model to operate within strict, schema-constrained roles on curated, deterministic evidence (like an AST code graph), CodeLens matches the quality of enterprise AI tools using free or cheap models.

## Why CodeLens?

Modern software moves fast, and peer reviews often become bottlenecks. Worse, subtle architectural drift or "blast radius" bugs (where changing a function in File A breaks a downstream consumer in File Z) are nearly impossible for a human to catch without hours of investigation.

CodeLens solves this by combining **deterministic static analysis** with **probabilistic AI reasoning**. 

1. We parse your codebase using `web-tree-sitter`.
2. We map out every symbol, function, and edge (dependency).
3. We embed these symbols using a high-speed embedding model.
4. When a PR is opened, the agent fetches the *exact* cross-file context it needs before it ever writes a review.
